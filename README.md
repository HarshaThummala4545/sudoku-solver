# 🧩 Sudoku Solver

An interactive Sudoku Solver built using HTML, CSS, JavaScript and the Backtracking Algorithm.

## 🚀 Features

- Solve Sudoku instantly
- Animated solving effect
- Responsive UI
- Pre-filled puzzle
- Modern glowing design
